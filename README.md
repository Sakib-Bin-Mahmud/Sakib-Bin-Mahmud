# Hi, I'm Sakib Mahmud Sovon 👋

Software Engineer @ [TechOptions](https://github.com/Sakib-Bin-Mahmud) · Computer Vision & Multimodal AI Researcher (Khulna University)

Building web products with **Python/FastAPI + React**, and researching **Vision-Language Models, Accessibility Tech, and Low-Resource NLP** — most recently real-time Bengali Sign Language translation and multilingual LLM reasoning.

## 🔬 Research Highlights

- 🏆 **99.56% test accuracy** on the BdSL49 benchmark with a compact 17.55 MB model — top performer among 6 architectures evaluated. Published at **IEEE COMPAS 2025** ([DOI](https://doi.org/10.1109/COMPAS67506.2025.11381726)).
- 🤟 Built a complete, real-time **Bengali Sign Language translation system** — continuous gesture-to-sentence generation for accessibility, using a YOLOv8n + MobileNetV2 two-stage pipeline.
- 🌱 Co-developed **NeuroPonic**, a multilingual, voice-enabled LLM reasoning framework for sustainable aquaponics, presented at **ICSASD 2026**.

**Publications:**
- S. P. Mistry, S. M. Sovon, M. Gain, R. Debnath. *A Lightweighted CNN-Based Framework for Real-Time Bengali Sign Language Recognition and Translation.* IEEE COMPAS 2025. [DOI: 10.1109/COMPAS67506.2025.11381726](https://doi.org/10.1109/COMPAS67506.2025.11381726)
- H. R. Shihab, S. M. Sovon, M. M. Hossain. *NeuroPonic: Exploring Multilingual, Voice-Enabled LLM Reasoning for Intelligent and Sustainable Aquaponics.* ICSASD 2026.
- S. M. Sovon, S. P. Mistry. *Text Generation from Bengali Sign Language (BdSL) Image using Convolutional Neural Networks.* IEEE CS Bangladesh Chapter Symposium 2024. [Paper details](https://s24.ieeecsbdc.org/papers/129)
